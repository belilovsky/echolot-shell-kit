# @echolot/shell-kit

Static-only primitives for ECHOLOT public shells. This package is an AVDS 4.8 adapter: it is deliberately limited to layout, accessible controls, localisation helpers and public projection contracts. It contains no credentials, server routes, collectors, schedules, model clients or background workers.

The adapter reference is `@sgeo/ui-kit@4.8.0` / AVDS `4.8.0` at `afbfd6ce886d4f258e39403f09d8538f24339777`; the upstream source API still needs a separate live verification before a production release.
